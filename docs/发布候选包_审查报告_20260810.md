# 发布候选包审查报告（2026-08-10）

> 2026-08-11 更新：候选包已追加一键预览启动器、多主题与默认无门户口令的本机预览模式，并移除早期外部云笔记同步器。下列 2026-08-10 验证证据保留为当时审查记录；当前代码请以 README、操作手册和最新验证结果为准。

## 结论

已生成一个可供人工审阅的独立发布候选包。候选包没有初始化 Git、没有创建提交、没有设置远端、没有推送，也没有修改原系统的 Vault、凭证、运行数据或嵌套仓库。

候选包通过脱敏、依赖、构建、单元、服务启动和依赖安全审计。它可以进入“人工内容、许可与产品体验审阅”阶段，但**尚不具备公开发布授权**。

## 范围与剥离结果

候选包只保留门户源码、前端源码、必要的 OCR 语言数据、测试、启动脚本与文档。

以下内容已排除：Vault、日记/笔记/电子书、照片、个人背景图、缓存、日志、构建产物、备份、虚拟环境、`.env`、Obsidian API 密钥、本机配置、个人审查报告，以及全部嵌套 Git 历史。

机器专属路径已替换为运行时变量：`BRAIN_WEB_VAULT`、`BRAIN_WEB_PYTHON`、`BRAIN_WEB_PORTAL_TOKEN` 和 `BRAIN_WEB_OBSIDIAN_API_KEY`。

## 发布适配与安全改造

- 前端的图谱组件从仓库外本地依赖改为候选包内的 MIT 源码；其 `d3-force` 依赖显式锁定在门户前端，避免本地文件依赖的隐式解析失败。
- 前端背景改为 CSS 环境背景，不再包含原有图片资产。
- Obsidian REST API 验证脚本改为参数/环境变量输入，不包含路径或密钥。REST 验证仍会写入并恢复测试内容，运行前必须备份 Vault。
- npm 依赖已升级并锁定到可构建的修复版本：Vite 8.2.1、React Router 7.18.2、React 插件 6.0.5、Tailwind Vite 插件 4.3.3、PostCSS 8.5.26。
- 新增发布卫生测试，检查源码中的旧机器路径/密钥端点标记、运行数据边界、环境模板、本地依赖与 `.gitignore`。

## 未验证项与残余风险

1. 为避免接触个人内容，本次没有用真实 Vault 或真实 Obsidian 插件做端到端写入验证；这些步骤必须由维护者在已备份的非生产副本上按操作手册执行。
2. OCR 中英语言数据的精确来源与再分发条款尚未完成人工复核。公开发布前必须处理 `THIRD_PARTY_NOTICES.md` 中的这一项。
3. 根目录 `LICENSE` 目前明确禁止自行公开分发，只是发布候选占位；维护者必须选择许可证并替换后，才可公开仓库。
4. 单元与构建验证不能替代浏览器内交互回归。尤其应人工检查首次口令流程、移动端布局、Obsidian 连接失败提示、OCR 和图谱交互。
5. 候选包的 `www/`、`node_modules/`、运行状态和 `.env` 均被忽略，必须通过 README 的安装步骤生成；这些生成物不应进入首提交。

## 进入 Git 前的动作

按 `docs/发布前审阅清单.md` 完成人工审阅，特别是许可证、第三方声明、敏感词命中、实际 Vault 冒烟和 Git 暂存差异。只有维护者明确批准后，才可以初始化 Git、创建首提交或设置远端。
