本地优先 · 写给自己看 · 个人知识门户

一个人的个人社交网站

把日记、说说、照片、待办、读书笔记和知识图谱汇聚在本机。无需上传日志，无需等待推荐算法，也无需把自己的生活包装给别人看。

查看 README 操作手册

它解决的不是笔记问题，而是回到自己生活的问题

松涧听澜把散落的本地记录重新组织成一个可浏览、可检索、可回顾的个人空间。

本地数据汇聚

日记、项目、领域、资源、图书馆和说说仍然是本机文件，但在门户里获得统一入口。

日志无需上传

短想法、照片和日记不需要进入云端平台。它们可以只是写给未来的自己。

自己写给自己看

像个人社交网站一样记录生活，但没有点赞、推荐和曝光压力，只有检索和回顾。

知识图谱

本地笔记变成可回看的地图

双链、文件夹、节点过滤和图形浏览帮助你重新看到记录之间的关系，而不改变 Markdown 的归属。

设计原则

它首先是个人系统，其次才是软件项目。

本地优先核心内容仍在 Obsidian Vault 和本机缓存中。
不上传日志个人动态不需要进入云端平台。
可回顾围绕时间轴、搜索、图谱和图书馆组织长期记忆。
可审查发布候选版剥离真实 Vault、凭证、缓存和运行态目录。

主要能力

日志按日期读写 Markdown，保留日常记录。
时间轴说说、照片、日志和文档改动按月汇总。
待办Markdown 看板、拖拽和并发保护。
图谱从本地 Vault 构建双链关系图。
图书馆电子书预览、分类、标签和读书笔记。
搜索文件名、正文和标签检索。
OCR粘贴图片识别，屏幕框选可选安装 Pillow。
多主题松涧、二次元、夜读、书房、专注。

一键启动

安装 Python 3.11+ 后，双击候选包中的启动脚本即可预览。没有真实 Vault 时会自动创建演示 Vault。

双击 启动门户.bat
默认打开 http://127.0.0.1:8765/
如端口被占用，自动尝试 8766 到 8776
