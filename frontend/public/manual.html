本地知识门户

这是随应用提供的简明操作提示。完整安装、备份和发布说明请阅读仓库根目录的 README.md 与 docs/操作手册.md。

首次启动

  1. 安装 Obsidian 与 Python，双击 启动门户.bat。
  2. 需要接入真实 Vault 时，复制 .env.example 为 .env，填写 BRAIN_WEB_VAULT。
  3. 需要编辑和全文检索时，在设置页按提示安装 Obsidian Local REST API 并粘贴 API Key。

日常操作

  • 门户只监听 127.0.0.1:8765；关闭前请使用 停止门户.bat。
  • Obsidian API 密钥只保留在浏览器当前会话，关闭标签页后需要重新粘贴。
  • 屏幕框选 OCR 需要 Pillow；若提示缺少依赖，按设置页或 README 的命令安装。

不要把 Vault、API 密钥、.env、state、www/cache 或截图提交到 Git。
